# 知行罗盘 V0.5 开发与测试状态

本版目标：长篇私密日记、分段 AES-256-GCM 加密、DOCX 本机提取、PDF 经单次用户批准后在 Windows 节点提取、历史版本恢复。

## 能力与边界

- 日记正文不设人工字数限制，但受到手机内存和存储容量影响。
- 每篇日记的正文拆成 32 KiB 加密分块，AES-256-GCM 独立认证；密钥在 Android 安全存储，数据库只存版本元数据。
- 原 V0.3.1/V0.4 日记密文迁移时先写新密文、校验还原，再清除旧安全存储键。
- 附件 DOCX/PDF 加密保存；Word 文字可本地提取，PDF 在用户明确授权后才发给私人 Windows 节点，原文件始终以密文保存。
- 保留历史版本，恢复时生成新版本。AI 仍逐次授权，长文单次分析须由用户确认范围。
- 普通 JSON 备份不包含私密日记和附件；如需跨设备迁移日记，后续须增加单独的加密备份。
- 不保证测试 APK 的签名与之前版本相同；不得建议有未备份日记的用户直接卸载旧版。
- GitHub Actions 测试和云端 APK 构建由 CI 结果决定；Android 真机、真实 DeepSeek 账号联调仍需要独立验收。
