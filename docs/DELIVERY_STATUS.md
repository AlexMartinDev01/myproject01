# 知行罗盘 V0.4 开发与实际测试状态

此文档区分代码实现、自动化验证、云端编译与未验证的实机行为。

| 项目 | 状态 | 证据及后续验证 |
|---|---|---|
| V0.3.2 DeepSeek 模型迁移 | 已修改 | 默认模型 deepseek-flash；旧模型不再被默认使用 |
| Windows Key 本地安全配置 | 已提供工具 | setup_windows 使用系统凭据库；需要用户自己的新 Key 完成真实联网测试 |
| AI 上游模拟成功/异常测试 | 已通过 | pytest backend/tests，14 项本地测试通过 |
| Android AI 真实请求 | 尚未验证 | 需用户的受信任节点和可用密钥；不使用聊天中泄露的旧 Key |
| V0.4 同源持续笔记 | 已开发，待 CI | 包含追加、编辑、历史、恢复、删除 |

| 笔记与来源版本持久化 | 已开发，待 CI | 通过数据库事务写入 revision，不覆盖旧版本 |
| 备份/恢复 | 已开发，待 CI | 普通数据 v1/v2 格式；不含私密日记/二进制附件 |
| Android 真机安装、所有按钮点击 | 未验证 | 需实际 Android 设备与 UI 测试环境 |
| Android 跨版本覆盖升级 | 未验证 | 需固定发行签名；当前 CI preview APK 不保证签名稳定 |
| 自动采集四个平台字幕、DOCX、长篇日记、AI 周/月回顾、知识网络 | 未开发 | 对应后续 V0.5–V0.7 及公开版阶段 |

**不能因为 APK 成功编译就声称 DeepSeek 在线实测、私密日记全量迁移或 Android 真机全功能无 Bug。**
