# 知行罗盘 V0.5.1 · AI 会话与阅读体验

## 本版本完成范围

- AI 长文回答改为 Markdown 富文本，底部固定输入框，支持多轮追问。
- 对话记录本地持久化：SQLite 保存元数据，正文以 AES-256-GCM 加密写入 app 私有文件，不上传 Render 保存。
- SQLite Schema 4 → 5 仅新增 ai_conversations / ai_messages，不修改旧日记。
- 会话标题搜索、改名、删除和继续对话；保留每条助手回复的资料 ID。
- AI 请求携带最多 30 条、约 40,000 字符上下文；后端严格约束长度与消息角色。
- “AI 提炼知识卡草稿”使用模型提炼一条待审核草稿，非全文复制。
- 多候选知识点选择、合并、去重属于 V0.5.2，未在本版实现。

## 安全边界

- 云端仍禁止遗留日记私密上传，V0.5.1 客户端也不会主动发送日记文本。
- 当前资料增强仍只选少量来源材料，完整相关性检索属于 V0.5.3。
- 本地普通 JSON 备份不包含加密聊天记录，后续需独立加密导出。
- Android 预览包签名仍不固定，不能保证覆盖安装；有数据的旧 APK 不得卸载。
- Render 服务分支 feature/knowledge-compass-cloud 关闭自动部署，需要到 Render 手工部署最新后端。
- CI 自动测试不等于 Android 真机或真实 DeepSeek 联调。

## 验收

后端多轮协议、安全测试；Flutter 会话加密存储/恢复/删除和 Markdown 渲染；Release APK 编译与发布。
真机键盘滚动、长期对话和 DeepSeek 真实计费调用仍需后续实测。
