# 知行罗盘 V0.5.2 · AI 候选知识点人工筛选

## 当前版本实现范围

- 对话里点击“提炼多个知识点”，使用现有 /v1/chat（不需要更新 Render）从这条 AI 回答提取 1–8 个 JSON 候选知识点。
- 来源详情也能将本地正文、持续笔记或 AI 摘要提炼成候选点；发往网关前要求用户确认，输入最多 6,500 字符。
- 每个候选可独立勾选、修改标题/解释/条件/反例/应用、选择专题。
- 本地根据规范化标题 + 字符双字元相似度提示可能重复的旧卡；用户选择新建或合并，**不会自动合并**。
- “仅保存选中项”：批量 SQLite 事务；如任何条目不合法或确切重复，整个批次回滚。
- 合并旧卡时保留原正文，追加新的经人工确认观点、应用和反例，并保留来源会话/消息 ID 及“未验证”标志。知识卡继续进入正常 JSON 备份。
- 普通知识资料、私密日记与聊天原文保持原有隔离；不会把私人日记交给旧版 Render 的 AI 提炼端点。
- 旧版“直接复制整篇 AI 回答到知识卡”入口改为人工筛选流程。手工建卡入口不再预填整篇原始材料。
- SQLite 主 schema 不升级（保持 5）；只对普通知识卡的 meta JSON 增加向后兼容字段，旧卡和旧日记保持原样。

## 能力边界与后续开发

- 这些候选由 AI 生成，虽然附带来源记录 ID，但来源 ID 仅表示本次提供资料，**不是已核实引用**。
- 如果 AI 返回不符合 JSON 协议的内容，明确提示失败且不保存；可再次提炼。不以原文全复制作为回退。
- 目前未提供 RAG 全文相关段落检索，属于 V0.5.3。知识关系网络属于 V0.7。
- 上一版多轮 API 历史需要 Render 更新后才真正生效；本版单轮知识提炼与旧 Render 网关兼容。
- APK 是预览版，签名未固定，不能保证覆盖安装旧 APK。已有本地日记、笔记用户不要卸载旧版。
- 真实 DeepSeek 联调与 Android 真机操作仍需独立验收，CI 的通过只说明可重复的代码自动测试及构建通过。

## 核心自动化验收

知识候选 JSON 解析、无效/重复回复拒绝、严格输入长度、标题相似度、原卡内容保留、仅选中项写入及多条保存失败全量回滚；原有安全/会话/日记/笔记回归测试；Android Release APK 编译及 GitHub Release 附件存在性检查。
