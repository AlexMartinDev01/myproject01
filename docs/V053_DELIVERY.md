# 知行罗盘 V0.5.3 · 本地资料检索增强 + 私密日记体验

## 已编写的功能

- 文件解析：对用户本机选择的 PDF、DOCX、TXT、Markdown 和 EPUB 尝试本地文字提取；保留来源文件。PDF 按页标记；扫描 PDF 没有文字时明确提示 OCR 未完成，绝不按标题编造正文。
- 建立 SQLite Schema 6 中的 knowledge_docs、knowledge_chunks，利用 SHA-256 内容指纹增量重建 1100 字符、120 字符交叠的片段，保存真实父来源、分段序号、正文偏移。来源正文、知识卡及持续笔记变更时自动刷新索引，删除后索引清理。日记不索引。
- AI 普通知识问答/决策：针对提问检索最多 9 个相关本地片段，再发送到现有 FastAPI \`/v1/chat\`，无需本轮更新 Render。模型需按后端现有格式用 [chunk_id] 标记引用；客户端支持点击已存在的 chunk 引用并跳转到真实片段，不能把未验证推断表述成有证据的事实。
- 由于是节省成本的个人版 MVP，本阶段是本地词项/中英文字串相关性检索，**不是语义向量搜索或已建立的完整知识图谱**。上限 30000 本地片段候选；过大的单条素材最多本机提取 600 万字符，其余保留在原始文件、提示不完整。
- 已保存日记正文与本次追加输入分离。手动加密保存成功后才清空本次输入，保留先前所有正文及历史修订。按钮提前到内容编辑框上方；不再 3 秒自动清除用户正在输入的草稿。
- 日记附件 PDF 使用内存中的解密字节 + in-app pdfx 阅读，DOCX 用内存提取文字供查看；附件点击“查看”，单独删除按钮。原始附件仍按块 AES-256-GCM 加密，解密数据不写到磁盘或发送 Render。
- 原 Render 网关仍旧禁止私密日记及私密 PDF 上传；本版本也不向其发送私人日记。

## 未包含 / 验收边界

- 尚无 OCR 扫描 PDF、语义向量检索、引用逐句自动事实校验、跨设备密文备份、真机多机兼容测试。
- GitHub CI 的后端/Flutter 测试通过才表示软件单测和 Android APK 编译通过；真实 DeepSeek AI 端到端检索、PDF 原生渲染及手机不同型号性能仍需手工联调。
- Render 按用户要求不更新；本地 RAG 复用既有 \`evidence\` 参数，但 V0.5.1 的会话上下文历史在旧 Render 中仍不生效。
- 由于旧版 Android 开发包可能使用不同签名，**已有日记的旧版不能直接卸载**。需要正式稳定签名与加密备份后才能安全升级。

## 验收重点

1. Schema 5 迁移 Schema 6，旧来源/持续笔记/知识卡/日记原样保留。
2. 远离材料开头的段落能被检索到，返回的 chunkId 能打开原始父记录和文字区间。
3. 编辑/删除后索引及时更新；私密日记不被纳入 RAG。
4. 导入文件不导致旧素材内容丢失；扫描 PDF 和格式错误能给出明确反馈。
5. 日记追加加密保存后输入框清空、历史保留；Word/PDF 加密附件可读且验证字节完整性。
6. Android Release APK 云端编译成功，直接发布 GitHub Release。

- Android Release 构建将 R8 对可选 `com.gemalto.jp2.JP2Decoder` 类的缺失降为警告；包含 JPEG2000/JPX 图片的 PDF 不保证可提取该图像中的文字，扫描/图片 PDF 仍不支持 OCR。
