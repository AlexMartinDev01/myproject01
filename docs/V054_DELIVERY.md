# 知行罗盘 V0.5.4 · 私密日记阅读与长篇编辑体验

本次在已完成并通过 CI 的 V0.5.3（本地知识索引、长文检索、来源引用、PDF/DOCX 本地处理）基础上改进日记交互，不改变 Render 服务端。

- 日记列表点击进入只读页面，默认查看本机解密的已保存正文与附件；点击 Word/PDF 附件可离线预览，继续写通过显式按钮进入编辑。
- 追加编辑页保存按钮放在 Scaffold 固定底栏，长篇输入或滚动时仍可见；只保留一个主要保存操作，减少重复按钮。
- 追加成功后才清空本次输入框；旧正文和历史版本保留。
- 退出未保存编辑内容时提供“继续写 / 放弃本次输入 / 保存并离开”，不再悄悄自动保存；保存失败保留输入内容。
- 私密日记正文不进入知识检索、RAG 或默认 AI 对话；本版未开放私密云端 AI 授权。
- 仍使用本机密文存储，不要求升级数据库 schema，不修改云端 API。

验收：后端测试、Flutter 静态检查、日记追加保存及只读页面测试、RAG 隐私隔离回归、Android APK Release 编译及发布。
