# 拾光盒 · 橘团动态桌宠版 V1.2.0

这是可直接由 GitHub Actions 构建的完整 Android 工程。

## 已整合功能
- Android 系统悬浮桌宠（TYPE_APPLICATION_OVERLAY）
- 橘团透明角色资源
- 随机眨眼 / 活跃动作 / 较明显摆手与兴奋动作
- 困倦 → 趴下闭眼睡觉 → 点击唤醒
- 点击互动和快捷面板
- 按住拖拽、松手自动吸附屏幕左右边缘
- 完成任务庆祝状态
- 提醒状态、震动和系统通知
- 快速记录
- 几分钟后提醒
- 前台服务保活

## APK
GitHub Actions 工作流会生成 `ShiguangBox-v1.2.0.apk`，Debug 签名可直接侧载安装。
