# USGM-05 · 浏览器数字孪生实验台（可交互离线版）

**打开 `index.html` 即可运行**（建议 Chrome/Edge；所有音频、WASM、手机代码均已嵌入，不需联网、无需 npm、无需 Python 服务器）。

这是用户确定的第一阶段实验设备：**5kg 透明圆形称重架（含 HX711）＋ESP32-C3 SuperMini＋MAX98357A＋4Ω 3W 喇叭**，手机代替实体显示屏。不购买实体数显屏 TM1637/OLED、RGB 灯、蜂鸣器、面包板或外壳。

## 1. 使用方法

1. 打开 `index.html`，左侧出现可旋转的 3D 几何工作台，右侧自动加载原 ESP32 固件的手机网页。
2. 鼠标拖动画布旋转视角，滚轮放大，点击 5kg 秤、HX711、ESP32-C3、功放、喇叭查看标注。
3. 点击或拖动 `75g`、`95g`、`135g` 水果到秤台，等待约 0.5 秒稳定判定；浏览器中的数值、手机和日志均来自**同一个 C-WASM 状态机**。
4. 每次称量完成后点击 `取走`，等待空秤重新布防，再放下一颗。持续放着不重复计数。
5. 右侧手机打开 `分级设置`，把小/中果上限改为 100g，中/大果上限改为 120g，保存。重新放 95g 水果，应判为小果。
6. `测试与标定` 可以进入虚拟 HX711 模式，进行虚拟空秤去皮与 100g 砝码跨度标定；模拟标定不是实物精度保证。
7. `测试报告` 查看记录、人工参考等级和报告导出；只有提供独立参考真值才可以计算准确率。
8. 开启 `浏览器音频试听`，允许页面播放音频，就可听到与固件同源的中文语音 PCM；不是 MAX98357A 的实物声学仿真。
9. `拔掉 HX711 数据线` 将阻止继续分级；`拔掉音频 DIN` 会阻止语音事件播放；`拔掉主电源` 会在模拟模型中停止服务。点击恢复可继续。
10. 展开实物照片参考区可对比你提供的真实 5kg 套件商品图。

**离线打开 HTML**：Chrome/Edge 双击文件即可；若受企业浏览器安全设置限制，可在解压目录运行 `python -m http.server 8000` 并访问 `http://127.0.0.1:8000/index.html`。

## 2. 真实代码复用

- `docs/usgm_core.c` / `docs/usgm_core.h`：原仓库核心 C 分级算法源代码。
- `docs/usgm_core_original.wasm`：原先由上述核心导出的 WASM，内嵌于 `index.html`，不是一套独立的模拟 if-else 假算法。
- `docs/index.html` / `docs/app.js` / `docs/report.mjs`：真实 ESP32-C3 固件网页的来源快照。浏览器加载其代码并用虚拟 HTTP 适配器驱动。
- `src/scene3d.js`：浏览器三维几何建模（相机透视、轨道旋转、元器件与导线、故障注入）。使用 Canvas 绘制软件三维几何，**不是精密扫描 GLB、WebGL 物理引擎或 SPICE 电路仿真**。
- `src/theme.css`：完整界面样式、手机布局和移动端适配。
- `src/build_offline.py`：从项目已有旧版浏览器仿真 HTML 生成独立离线 HTML；原始 HTML 路径见脚本中的 `BASE`，本交付 ZIP 已自带成品，无需执行该脚本。

## 3. 验证方法

自动浏览器测试已在 Chromium 上实际执行，运行记录见 `docs/browser_e2e_results.json`。

```bash
python tests/e2e_browser.py
python tests/responsive_browser.py
```

测试包含：WASM 启动、原手机页面加载、三维轨道改变、选中元器件、75/95/135g 三档判定、重复放置防重计数、手机保存阈值到原 C 核心、断线及恢复、断电状态、报告与 CSV、JS 零异常、390px 手机宽度测试。

如果 Chromium 无法使用 `file://` 自动化访问，本项目的 Playwright 测试使用 `page.set_content(...)` 直接加载相同的离线文件；这一方式与在浏览器中手动打开文件的 URI 权限并不完全等价。

## 4. 重要边界和安全

- 目前验证的是 **BROWSER_MODEL**，不是实际的 5kg HX711 电气模型或真实 ESP32 固件在芯片仿真器中运行；软件原始 ADC 读数是合成值。
- 原始用户商品图只有一个视角，模型整体形态参考了透明双层圆盘、铝合金梁、PCB；没有实测尺寸，不能说几何 100% 还原。
- GPIO 和连接线路仅依据已制定设计：HX711 GPIO0/1，MAX98357A GPIO4/5/6；5V 电源与 3.3V 逻辑必须在到货后确认。不能将未知 5V HX711 数据线直接接到 ESP32-C3。
- 不能用浏览器音频推断实际 MAX98357A 的音量、失真、噪声或电流；这些必须在真实功放＋喇叭上验证。
- 真正监听现有地秤内部显示通信属于后续另一研发任务，与当前 HX711 自建秤实验不是同一采集接口。
- 浏览器数字孪生的测试报告不得当作实物称量精度、制造验收或已适配所有地秤的证据。

## 5. 后续实物接入

等你收到实物后，第一步检查：5kg 套件四芯端子定义、工作电压，ESP32-C3 SuperMini 的具体板载引脚，MAX98357A 输入端和喇叭阻抗，以及 USB 5V 供电余量。实物固件来源仍在同一仓库 `usgm-05/firmware`，不应把本浏览器几何/故障模型烧录到 ESP32-C3。
