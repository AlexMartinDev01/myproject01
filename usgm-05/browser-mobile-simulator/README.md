# USGM-05 — 5kg 圆形秤 + 手机全流程浏览器仿真实验台

## 先看清仿真的真实性范围

- 左侧展示用户实际选择的 **5kg 圆形 HX711 称重架**原商品图片的裁剪片段；水果重量、HX711 ADC 计数和标定都是软件模拟，不是实物传感器采样。
- 右侧手机屏幕使用 **原 ESP32 固件的 `index.html`、`app.js` 和 `report.mjs`**。为了在单文件中离线打开，替换 HTTP 传输为页面内的模拟设备 API，去掉了 ES Module 导入；不是一张静态 UI 截图。
- 分级状态机基于 `firmware/components/usgm_core/usgm_core.c` 编译到 WebAssembly。不是在浏览器里凭空另写了一套 if/else 算法。
- 中文语音试听使用固件的 PCM 文件，由浏览器 WebAudio 播放；不是 MAX98357A 功放的真实输出和音质验证。
- 单文件实验台 **不代表 Wokwi 芯片级运行已验证**。若要运行真正的虚拟 ESP32-C3 + HX711 电路，仍需 Wokwi 平台和在 Wokwi 下启动 ESP-IDF 仿真固件。
- 模拟的 HX711 标定流程不能替代实际 5kg 传感器精度校验；浏览器报告不可用于宣称实物准确率。

## 怎么操作

直接双击 `USGM-05_5kg圆形秤_手机调控全过程_可交互仿真.html`，在最新版 Chrome 或 Edge 中打开（全部资源已嵌入，不需要互联网）。

1. 点击左侧「▶ 一键运行手机调控＋称重分级全流程」，等待程序在手机里完成设置、模拟校准、三档称重、查看报告。
2. 也可以自己在右侧手机点「分级设置」，调整小中边界、 中大边界并点击「保存阈值」。
3. 在「测试与标定」里切换「虚拟 HX711」，执行「空秤零点标定」，在左边模拟放上 100g，再执行跨度标定；最后取走砝码。
4. 左边按 75g、95g、135g，三颗水果每称完要按「取走/空秤」。看实时监控中的数量与等级。
5. 在手机「测试报告」中检查记录并点击 CSV 导出；仅人工填写模拟参考等级后才会显示已标注子集准确率，仍不属于硬件验收。
6. 点击「开启浏览器音频试听」，需浏览器允许播放声音，可试听项目中包含的离线语音素材。
