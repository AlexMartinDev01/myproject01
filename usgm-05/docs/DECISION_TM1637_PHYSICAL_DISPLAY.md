# USGM-05 需求变更：实体 TM1637 数码管（方案 B）

状态：**用户已选择方案 B，设计冻结；固件驱动、Wokwi 图与实物尚未按此更新，不得标为已实现。**

## 目标
在最终实体实验装置中增加一块 **四位、每位支持小数点（DP）的 TM1637 数码管模块**，而不只是网页绘制的虚拟显示。浏览器数字孪生和 Wokwi 也应该显示**同一实体数码管型号**。用户先前已取消 RGB 灯、蜂鸣器、OLED、面包板与外壳；这些选择不变。MAX98357A＋4Ω 3W 扬声器以及手机本地设置保留。

## 显示规范
- 单位：克（g）；物理模块通常不具备字母“g”的段码，旁边用标签或 UI 标出单位。
- 0g → 0.0；75g → 75.0；95g → 95.0；135g → 135.0；999.9g → 999.9。
- 当有效值为 1000–5000g 时，显示整数克（1000、5000），不误显示为其他值；在 4 位容量不足或不可表示时显示明确错误标识（如 ----），不截断高位数字。
- 未标定、采集失效和过载时显示特定故障码/横杠；数码管显示和手机读数来自同一规范化重量值。
- 用户依然在手机上设置“大小果”阈值；显示屏不代替手机。

## GPIO 建议（ESP32-C3 SuperMini，必须核对实际板引脚）
| GPIO | 用途 |
| --- | --- |
| 0 | HX711 DT / DOUT |
| 1 | HX711 SCK |
| 3 | TM1637 CLK |
| 7 | TM1637 DIO（双向，包括 ACK） |
| 4 | MAX98357A BCLK |
| 5 | MAX98357A LRC / WS |
| 6 | MAX98357A DIN |
| 10 | 备用；原 Wokwi 仿真声音代理需从 GPIO7 移走，或停用 |

## 电气保护
- TM1637 数据手册工作电源 4.5–5.5V。VCC 优先使用合格的 5V 支路，GND 与控制器低压逻辑端建立安全公共参考。
- **不要将 5V DIO/CLK 的上拉信号直接连接 ESP32 的 3.3V GPIO。**
- 使用兼容 TM1637 ACK/DIO 双向传输的两通道 3.3V↔5V 电平转换，电气确认通过后才能焊接。
- **选购 DP 小数点版，不要只有中间冒号的时钟版。** TM1637 仅用 CLK、DIO 通信，协议非标准 I²C。
- GPIO2/8/9 启动绑定位尽量不占用；实际控制板排针与供电规格需要核对。

## Wokwi / 浏览器数字孪生验收
1. 增加 `wokwi-tm1637-7segment`，`attrs.type="dp"`，真实连线 GPIO3 CLK / GPIO7 DIO、5V 和 GND。
2. 原 Wokwi 仿真声音代理占用 GPIO7，必须移到空闲引脚（拟 GPIO10）后再编译，否则严重冲突。
3. 增加 TM1637 驱动模块及测试，运行时虚拟数码管、原 C 分级核心、手机显示同源重量；**不使用旁路动画伪造数码管刷新**。
4. 验证 0、75、80、95、110、135、999.9、1000、5000g，以及去皮、掉线、未标定、溢出。
5. 手机阈值设置、语音与分级报告功能保持不变；Wokwi 由于不支持 ESP32-C3 I²S，只能模拟触发意图或声音代理，不能声称完成 MAX98357A 中文音频仿真。
6. 后续实物测试必须验证 TM1637 在功放播报同时是否闪烁、是否影响 HX711 稳定读取或 Wi-Fi。

## 正式实施前需采购
- TM1637 四位 DP 小数点版（不要冒号版），1块；
- 两路适用于 CLK、DIO 的 3.3V/5V 电平转换模块（具体型号应根据成品板测量确定），1块；
- 匹配插头/杜邦线若干；5V 电源电流余量按模块及功放共同评估。
