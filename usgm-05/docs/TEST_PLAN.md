# USGM-05 完整验收与实验设计

## 1. 测试类别（不可互相替代）

| 类别 | 测试输入 | 可得结论 | 不能得出 |
|---|---|---|---|
| C 状态机单元/压力测试 | 计算机生成整数毫克事件 | 区间边界、防重复、稳定与断线状态机逻辑 | 实际 ESP32 时序与电气安全 |
| Node.js 报告单测 | 合成事件与独立真值 | 报告分母、P95、混淆矩阵和 HTML 转义 | 实测称重精度 |
| 原型传感器试验 | 自建 HX711 + 砝码 | 该 HX711+机械结构称重表现 | 真实地秤显示旁路兼容性 |
| 显示信号监听试验 | TM1637 或真实地秤显示驱动信号 | 对测试协议/被测秤的显示还原能力 | 对所有电子秤适用 |
| 计量影响测试 | 原秤接入模块前/后 | 对该型号原秤的影响 | 所有型号毫无影响 |

## 2. 软件自动化门槛

1. 边界 19.999 / 20.000 / 79.999 / 80.000 / 109.999 / 110.000 g 正确。
2. 上电载物不能直接判成一颗果：必须先连续确认空秤。
3. 500ms 内波动大于阈值则重置稳定窗口；未稳定不播报。
4. 一次放取只计数一次；重量短暂触零不误复位。
5. 采样中断时保持等待取走锁定，不能因断线形成新事件。
6. 修改阈值必须再次确认空秤。错误配置拒绝。
7. 报告缺少独立参考等级时 `acceptedAccuracy` 必须为 null。
8. HTML 中的报告标题必须安全转义，防止脚本注入。
9. 正常化数据不能被模拟输入冒充真实 HX711 测量。
10. 存储容量达到限制不得覆盖既有记录，异常必须告警。

## 3. 烧录和电路接线验收（待实测）

- HX711 套件四线插头由厂家图确认；核实 VCC 为 3.3V 时 DOUT 最高电压不超过 ESP32 GPIO 允许范围。
- MAX98357A 由 5V 电源支路供电，SPK+/SPK− 只连接喇叭两端。
- 负载切换、响声最大音量、手机同时访问期间不出现看门狗复位、Brownout 或异常温升。
- 不同 USB 电源测试和多次上电，记录所有异常。
- 使用已知质量 50g、100g、200g 以及其他未参与标定的砝码做重复性、线性、漂移验证（适当考虑5kg满量程）。
- 冷启动非零负载：设备启动需等待空秤，不能把已经放在秤上的水果自动视为一次完整放取。
- 模拟与 HX711 批次隔离，重启后完整事件可恢复；文件系统损坏不伪造完整日志。
- 72h 实验连续运行；不同 Wi-Fi 连接/断开、功放工作、USB 上电干扰下记录表现。

## 4. 可量化的真实实验设计（硬件到货后）

- 对每颗水果记录**独立参考重量和标签**，不要用 USGM 自己的分级结果当参考。
- 包含区间边界附近样本和远离边界的样本。
- 保留未成功解析、断线、故障和漏掉的人工放取尝试，单独计算覆盖率。
- 报告原始样本总数、有效读数数、参考标签数、正确数、误分类数、拒绝数、重复计数数、延迟 P50/P95。
- 记录原秤型号、固件版本、量程、显示分度值、数据接口结构、电压、是否会影响原秤。
- 通过一台真实秤只说明**该型号**兼容；不说明所有地秤兼容。

## 5. 已知风险与退出条件

- 如果单板在播放中文语音 / Wi-Fi 工作时无法保证数字显示总线的高速采样，需要重新评估 ESP32-S3 或专用采集方案。
- 如果真实秤内部不提供可访问的低压数字显示通信接口，需要停止用本方案直接接线，避免误焊。
- 如果 HX711 的重复性和零点漂移无法满足水果等级边界要求，先解决称重系统精度，不得通过平滑软件制造虚假的精度。
- 原秤的电气安全、计量封印、防水以及 EMC 必须针对实际型号验证。
