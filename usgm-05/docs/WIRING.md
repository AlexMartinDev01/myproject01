# HX711 实验板接线与故障排查

## 一、当前被允许的接线对象

只允许你购买的 **HX711+5kg自建称重台套件**，在确认其标示引脚、电平与电源规格后接 ESP32-C3。

| ESP32-C3 | HX711 |
|---|---|
| 3V3 | VCC（模块支持3.3V时才可） |
| GND | GND |
| GPIO0 | DOUT/DT |
| GPIO1 | SCK |

| ESP32-C3 / 电源 | MAX98357A |
|---|---|
| GPIO4 | BCLK |
| GPIO5 | LRC / WS |
| GPIO6 | DIN |
| 合格 USB 5V 支路 | VIN |
| 公共地 | GND |
| 扬声器两线 | SPK+、SPK−，**不得接地** |

没有面包板也可以使用可靠的 2.54mm 连接器、杜邦线和小型多路供电分配端子。务必做好线束固定。接线后先关电核对再上电。

## 二、最常见的错误

- 5V HX711 的 DOUT 高电平可能伤害 ESP32；没有验证前不接。
- 套件四芯线颜色不是国际统一标准，必须由丝印或商家接线图确认。
- 功放模块不允许从 ESP32 3.3V 小稳压器直接大功率供电。
- SPK− 不是 GND。
- 不能直接使用你这块 HX711 去并联到已经由原地秤激励供电的传感器上。
- 实验时秤台需要在说明书要求的受力方向上固定，称重梁不能被夹死、接触桌面或过载。
- 没有任何实测原秤的内部波形、PCB 或显示芯片资料，不提供所谓万能焊点图。

## 三、故障检查

| 现象 | 检查项目 |
|---|---|
| 手机能连但无真实重量 | `HX711` 模式、零点和跨度是否完成、传感器供电与端子 |
| 状态一直 ARMING | 必须先确保空秤并持续稳定300ms |
| 看似称到重量却没有播报 | 是否满足稳定500ms；是否达到最小有效重量；是否已播报需取走 |
| 播报时ESP32重启 | 检查功放供电支路、电源余量、地线/去耦 |
| 重复称重不计数 | 必须先降到空秤阈值以下，持续300ms重新布防 |
| CSV记录数量异常 | SPIFFS完整性提示、是否达到512条上限、是否修改/删除批次 |
